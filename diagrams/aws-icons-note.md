# AWS Icons Note

Mermaid does not support official AWS architecture icons.

## Recommendation
For portfolio or presentation-quality diagrams:
- use draw.io / diagrams.net
- use official AWS Architecture Icons
- export PNG/SVG versions into `diagrams/assets/`

## Suggested draw.io asset plan
- `diagrams/assets/hld.drawio`
- `diagrams/assets/lld.drawio`
- `diagrams/assets/runtime.drawio`
- `diagrams/assets/deployment.drawio`

## Suggested exports
- `diagrams/assets/hld.png`
- `diagrams/assets/lld.png`
- `diagrams/assets/runtime.png`
- `diagrams/assets/deployment.png`
